# Calculator

A desktop calculator application built using Python and Tkinter, featuring a dark-themed interface, advanced mathematical operations, and calculation history.

## Features

* Basic arithmetic operations
* Exponentiation and square root
* Percentage and reciprocal calculations
* Parentheses support
* Keyboard input support
* Calculation history
* Custom dark-themed interface
* Standalone Windows executable

## Installation

### Option 1: Run the Windows executable

1. Download `Calculator.exe` from the project's Releases section.
2. Double-click the executable to launch the calculator.

### Option 2: Run from source

**Requirements:** Python 3 and Tkinter.

1. Clone the repository:

   ```bash
   git clone https://github.com/deepaktandi/calculator-app.git
   ```

2. Open the project folder:

   ```bash
   cd calculator-app
   ```

3. Run the application:

   ```bash
   python main.py
   ```
